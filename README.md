# 📝 Task Management

## 📌 Overview

**Task Management** is a user-friendly desktop application designed to help boost productivity by allowing users to effectively manage their daily tasks. The goal of this project is to provide a simple yet powerful tool for creating, editing, and organizing tasks based on priorities, deadlines, and categories.

## 🚀 Project Goal

To create a cross-platform desktop application for personal task tracking, offering flexible customization and filtering options to stay organized and productive.

---


## ⚙️ Features

- ✅ Add, edit, and delete tasks  
- 📅 Set deadlines using a built-in calendar widget  
- 📝 Specify task title, description, category, and difficulty level  
- 🔍 Filter tasks by:
  - deadline  
  - difficulty level  
  - category  
- 📂 Categorize tasks for better organization  
- 🔄 Track task status (e.g., “In Progress”, “Completed”)

---

## 🧩 Technologies Used

- **Python**  
- **PyQt6** – for the graphical user interface  
- **SQLite** – for data storage  
- **DBeaver** – for database management
